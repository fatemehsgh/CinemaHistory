## ✨ امکانات و قابلیت‌های کلیدی

- 🎬 **تفکیک کامل فیلم و سریال:** امکان انتخاب نوع اثر (فیلم / سریال) با انطباق هوشمند عنوان‌ها، برچسب‌ها و فیلترها
- 🌐 **جستجوی زنده در اینترنت:** دریافت خودکار پوستر باکیفیت، سال ساخت و خلاصه‌داستان به زبان فارسی
- 🏷️ **انتخاب‌گر تعاملی ژانرها:** چیپ‌های شیک و چندانتخابی ژانرها (درام، علمی‌تخیلی، اکشن، کمدی و ...) با شمارنده فعال
- ⭐ **سیستم امتیازدهی دقیق:** نمره‌دهی تعاملی از ۱ تا ۱۰ ستاره با برچسب‌های توصیفی (شاهکار، عالی، خوب و ...)
- 📅 **مدیریت سال تماشا و سال ساخت:** پیش‌فرض هوشمند سال جاری و تقویم شمسی
- 🔍 **فیلتر و جستجوی پیشرفته:** فیلتر براساس نوع اثر (فیلم/سریال)، سال تماشا، امتیاز، ژانر و جستجوی متنی لحظه‌ای
- 📊 **داشبورد آمار و تحلیل:** نمایش تعداد کل آثار دیده‌شده، میانگین نمرات و توزیع ژانرها
- 🎨 **طراحی لوکس شیشه‌ای (Glassmorphism):** رابط کاربری تیره، روان، ریسپانسیو و بهینه برای موبایل و دسکتاپ
- 💾 **پشتیبانی دوگانه (Static & Full-Stack):** قابلیت اجرا به صورت مستقیم روی GitHub Pages (با ذخیره‌سازی LocalStorage) یا با سرور اختصاصی Node.js

## 🚀 نحوه اجرای محلی (Local Run)

### پیش‌نیازها:
- نصب بودن [Node.js](https://nodejs.org/) (نسخه ۱۶ به بالا)

### مراحل اجرا:
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/fatemehsgh/CinemaHistory.git

# ۲. ورود به پوشه پروژه
cd CinemaHistory

# ۳. اجرای سرور
npm start
# یا: node server.js
```

سپس در مرورگر خود آدرس زیر را باز کنید:
```
http://localhost:3000
```

## ☁️ همگام‌سازی ابری و اتصال همزمان چند دستگاه (Supabase Cloud Sync)

سینما لاگ از دیتابیس ابری رایگان **[Supabase](https://supabase.com)** پشتیبانی می‌کند تا بتوانید با یک اکانت واحد، به صورت همزمان از کامپیوتر، لپ‌تاپ، تبلت و گوشی موبایل به اطلاعات خود دسترسی داشته باشید و فیلم‌ها به صورت زنده (Realtime) بین تمام دستگاه‌ها همگام شوند.

### نحوه راه‌اندازی (تنها در ۲ دقیقه):
1. در سایت **[supabase.com](https://supabase.com)** یک حساب و پروژه رایگان بسازید.
2. از منوی سمت چپ وارد بخش **SQL Editor** شده و تمام کدهای فایل [`supabase-setup.sql`](supabase-setup.sql) را در آن کپی کرده و دکمه **Run** را بزنید.
3. در داشبورد Supabase از بخش **Project Settings > API**:
   - مقدار **Project URL**
   - مقدار **anon public key**  
   را کپی کرده و در برنامه روی آیکون پروفایل (بالا سمت چپ) > بخش **«همگام‌سازی ابری»** وارد کرده و ذخیره نمایید.
4. با زدن دکمه **«🔗 کپی لینک سریع اتصال برای گوشی»**، می‌توانید لینک آماده را برای گوشی خود بفرستید تا با یک لمس، موبایل نیز متصل شود!

## ⚙️ فعال‌سازی GitHub Pages (در صورت نیاز به تنظیم مجدد)

1. در صفحه مخزن وارد تب **Settings** شوید.
2. از منوی سمت چپ به بخش **Pages** بروید.
3. در قسمت **Build and deployment**:
   - گزینه **Source** را روی `Deploy from a branch` بگذارید.
   - شاخه را روی **`main`** و پوشه را روی **`/ (root)`** انتخاب و ذخیره (**Save**) کنید.
4. آدرس سایت شما در دسترس خواهد بود:  
   `https://fatemehsgh.github.io/CinemaHistory/`
